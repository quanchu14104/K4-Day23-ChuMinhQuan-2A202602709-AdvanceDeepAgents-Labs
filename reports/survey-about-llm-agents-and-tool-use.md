# Survey of LLM Agents and Tool Use

**Học viên:** Chu Minh Quân | **MSSV:** 2A202602709

## TL;DR
This report provides a comprehensive overview of LLM agents and tool use, covering foundational concepts, core methodologies, empirical benchmarks, and key representative systems. It highlights the evolution of tool use in LLM agents, the development of structured frameworks, and the introduction of evaluation metrics for tool-using agents.

## Background & Motivation
LLM agents have emerged as a significant area of research, with applications ranging from task planning and tool usage to multi-agent systems. The development of unified modeling frameworks and evaluation metrics has been crucial in advancing the capabilities of LLM agents. This report aims to provide a comprehensive overview of the current state of research in LLM agents and tool use.

## Foundational Concepts, Architectures, and Mathematical Formulations
The foundational concepts of LLM agents include the development of unified modeling frameworks [1][2] and benchmarks for workflow-guided planning [3][4]. These frameworks define clear component boundaries and propose taxonomies of core-agents to enhance modularity. The architecture-aware evaluation metrics [5] provide a structured approach to assessing LLM agent components.

## Core Algorithms, Methodologies, and Training Paradigms
The core methodologies for LLM agents include the development of structured frameworks for task planning and tool usage [6] and systematic deconstruction of LLM agent systems [7]. The evaluation metrics for tool-using agents [8] include Path Correctness, PC-KTC, Prefix Criticality, Harmful-Call Rate, and Efficiency. The AutoTools framework [9] enables LLMs to automate the tool-use workflow, transforming tool documentation into callable functions and integrating these functions into executable programs.

## Empirical Benchmarks, Capabilities, and Key Representative Systems
The empirical benchmarks for LLM agents include the evolution of tool use in LLM agents [10][11], the ToolCPT method for enhancing tool utilization via continuous pre-training [12], and the Tool-R1 framework for sample-efficient reinforcement learning in agentic tool use [13]. These benchmarks highlight the shift in evaluation paradigms for multi-tool agents and the development of robust agents through continuous pre-training.

## Trends and Open Problems
The trends in LLM agents and tool use include the development of unified modeling frameworks, the introduction of evaluation metrics for tool-using agents, and the evolution of tool use in LLM agents. Open problems include the need for improved detection of failure modes in agent sequences, the development of more sophisticated task-oriented development and multi-agent systems, and the enhancement of tool utilization through continuous pre-training.
